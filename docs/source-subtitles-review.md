# 来源外挂字幕代码审查

日期：2026-09-27。范围：公开 v1.0.9 之后新增的来源外挂字幕支持。

## Standards

- 两个独立审查分别检查代码规范和需求实现。
- 发现 1 项低优先级职责划分问题：来源响应解析及请求头策略位于 Models。
- 已将原实现移至 `Services/SourceSubtitleParser.swift`，模型仅保留值字段；调用方、测试和生成的 Xcode 工程同步更新。复查确认方法实现不变。
- 修正后无未解决规范项，未发现阻断级安全或并发问题。

## Spec

- 接口返回的字幕列表经过解析、详情状态、普通/全屏播放器传入 mpv；菜单按名称列出，支持选择、切换、关闭及加载后复用。
- 加载失败只更新字幕状态，不中断视频；同一字幕可重新选择重试。
- 切集和关闭取消旧下载；完成回调核验会话及请求标识，原生加载完成后按当前选择处理。
- 全屏保持字幕选择及时间偏移，VideoToolbox 硬解配置不变。
- 系统播放器和 VLC 在发现来源字幕时提供切换到 mpv 的入口。
- 需求审查未发现未解决项。兼容范围以接口实际返回的字幕列表为前提；未知具体来源尚未逐一实测，画面中的硬字幕不能拆分选择。
